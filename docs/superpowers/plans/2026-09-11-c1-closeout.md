# C1 Closeout Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development. One
> implementer and one reviewer maximum; execute the numbered packet, then review.

**Goal:** Complete the fixed C1 checklist without reopening completed work.
**Architecture:** Preserve the coupled solver and compiled model. Replace
full-row ownership with bounded preparation/replay, keeping existing eager
behavior and authenticated immutable chunk reuse.
**Tech Stack:** Python 3.12+, NumPy, SciPy, Numba and existing frame/model APIs.
**Spec:** [C1 closeout](../specs/2026-09-11-c1-closeout.md).

## Global constraints

- At most two subagents; implementation at high effort, independent review.
- Repository edits use apply_patch. Preserve unrelated QR work and versions.
- Preserve arithmetic order, weight semantics, model identity and certificates.
- New solver behavior needs a failing regression before the production change.
- Time full fits separately from instrumentation; use existing fixtures.
- Cap the entire 10-million-row benchmark process at 10 minutes and the
  100-million-row process at 60 minutes, including setup. Allow 10 seconds for
  termination before forcing exit. Record any timeout as incomplete; it cannot
  satisfy a numerical or capacity gate.
- No optional review ideas or additional acceptance targets enter this plan.

## Packet 2: typed row storage and source authority (items 2–3, partial)

Implement the exact private interface and byte limits in the specification's
"Packet 2 storage and verification contract". This packet is usable storage
with verified replay. It does not connect public fitting, compilation,
initialization, likelihood binding or endpoint output, and checks off none of
the seven full C1 acceptance items by itself.

**Owned files:** Create `src/superglm/distributional/row_store.py` for the
format, writer, bounded reader and authority types. Create
`tests/test_distributional_row_store.py` for the tests below. The implementer
may update this packet's checkboxes and writes its frozen receipt to
`.superpowers/sdd/2026-09-11-c1-closeout/packet2-implementation.md`.
No existing production module, export, artifact schema or dependency changes.
The implementer is not alone; preserve Packet 1 and unrelated QR edits.

**Consumes:** Typed column batches and JSON metadata supplied explicitly to
`RowStoreWriter`. **Produces:** `PreparedRowStore`, `VerifiedRowBlock` and
`RowRangeAuthority`, with the exact signatures in the spec. Later compiler
and likelihood consumers read these objects directly; this packet must not
add unimplemented adapter classes or protocols.
