# C1 Closeout Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development. One
> implementer and one reviewer maximum; execute the numbered packet, then review.

**Goal:** Complete the fixed C1 checklist without reopening completed work.
**Architecture:** Preserve the coupled solver and compiled model. Replace
full-row ownership with bounded preparation/replay, keeping existing eager
behavior and authenticated immutable chunk reuse.
**Tech Stack:** Python 3.12+, NumPy, SciPy, Numba and existing frame/model APIs.
**Spec:** [C1 closeout](../specs/2026-09-11-c1-closeout.md).

## Global constraints

- At most two subagents; implementation at high effort, independent review.
- Repository edits use apply_patch. Preserve unrelated QR work and versions.
- Preserve arithmetic order, weight semantics, model identity and certificates.
- New solver behavior needs a failing regression before the production change.
- Time full fits separately from instrumentation; use existing fixtures.
- No optional review ideas or additional acceptance targets enter this plan.

## Packet 2: typed row storage and source authority (items 2–3, partial)

Implement the exact private interface and byte limits in the specification's
"Packet 2 storage and verification contract". This packet is usable storage
with verified replay. It does not connect public fitting, compilation,
initialization, likelihood binding or endpoint output, and checks off none of
the seven full C1 acceptance items by itself.

**Owned files:** Create `src/superglm/distributional/row_store.py` for the
format, writer, bounded reader and authority types. Create
`tests/test_distributional_row_store.py` for the tests below. The implementer
may update this packet's checkboxes and writes its frozen receipt to
`.superpowers/sdd/2026-09-11-c1-closeout/packet2-implementation.md`.
No existing production module, export, artifact schema or dependency changes.
The implementer is not alone; preserve Packet 1 and unrelated QR edits.

**Consumes:** Typed column batches and JSON metadata supplied explicitly to
`RowStoreWriter`. **Produces:** `PreparedRowStore`, `VerifiedRowBlock` and
`RowRangeAuthority`, with the exact signatures in the spec. Later compiler
and likelihood consumers read these objects directly; this packet must not
add unimplemented adapter classes or protocols.

13. [ ] Write and run the initial failing storage test before adding production
    code. Use arbitrary-sized append batches and request an unaligned range:

    ```python
    schema = (RowColumn("y", "<f8"), RowColumn("code", "<i4"))
    writer = RowStoreWriter(tmp_path / "rows", schema, block_rows=4)
    writer.append({"y": np.arange(3, dtype="<f8"),
                   "code": np.arange(3, dtype="<i4")})
    writer.append({"y": np.arange(3, 9, dtype="<f8"),
                   "code": np.arange(3, 9, dtype="<i4")})
    store = writer.finish()
    block = store.read_verified(3, 7)
    np.testing.assert_array_equal(block.columns["y"], np.arange(3, 7))
    assert [(b.start, b.stop) for b in store.iter_verified()] == [(0, 4), (4, 8), (8, 9)]
    assert PreparedRowStore.open(tmp_path / "rows",
                                 expected_generation=store.generation).generation == store.generation
    ```

    Pass means this fails because the interface does not exist, then passes
    after steps 14–16. Retain that initial failure in the receipt.
14. [ ] Implement frozen schema/authority/result records and the writer using
    the spec's four dtypes, canonical JSON and 56-byte index records. Accumulate
    at most one bounded pending block; flush full blocks and a final tail.
    Copy strided inputs in bounded slices. Reject mismatched names, lengths,
    dtypes, object arrays, oversized metadata and invalid limits before
    publication. Enforce the row/index budgets before accepting an append.
    Preserve bit patterns and caller input ownership. Finish publishes the
    manifest last; existing destinations are never overwritten. Test two
    identical sources built with different append boundaries have the same
    generation, and source-array mutation after append cannot change the store.
15. [ ] Implement open and generation validation from exact bounded file reads.
    Check regular files, symlinks, format/schema, index SHA256, record coverage
    and sizes before allocating payload buffers. Retain raw immutable index
    bytes and decode records with `Struct.unpack_from`; do not build a record
    list. Reject duplicate JSON keys, invalid dtype tags, forged counts,
    oversized/truncated metadata and unexpected generation. Test incomplete
    publication, successful reopen, abort of unpublished work, and persistence
    after all writer/store objects are collected.
16. [ ] Implement the common range verification path and use it for both
    `read_verified` and `verify_range`. Verify pinned metadata before/after I/O,
    hash one touched payload at a time, and assemble only the requested rows.
    Build returned columns on immutable bytes and expose an immutable mapping.
    Iteration delegates to this path and releases previous yielded buffers.
    Test first/last rows, exact boundaries, unaligned two-block ranges and a
    one-row tail. Refuse negative, reversed, empty, oversized, out-of-range,
    boolean and noninteger ranges. Assert exact values/dtypes and independent
    byte ownership; changing a source file cannot change a returned snapshot.
17. [ ] Exercise authority failure after open and after an apparent cache hit.
    Cache an owned result and its `RowRangeAuthority` in the test, then call
    `verify_range` before reuse. Mutate a block byte and restore its timestamp;
    verification must raise `RowStoreIntegrityError` instead of returning the
    cache entry. Repeat for index/manifest changes, truncation, a replaced
    generation and corruption in the second block of an unaligned range.
    Inject metadata mutation between the first check and payload completion
    to prove the final check runs. Restore exact bytes and show unchanged
    content can reopen and replay. A same-length mutation with unchanged
    timestamps must still fail; stat identity or read-only flags cannot pass
    this test.
18. [ ] Measure actual bounded allocation and lifetime in focused tests. Use a
    source larger than three payload blocks, then a wider source that lowers
    effective `block_rows`. Instrument actual file read request sizes and
    buffer allocation/ownership; observe the spec's byte bound, not only a
    reported limit field. Use weak references to prove yielded arrays do not
    retain a store and the iterator does not retain a previous block. Refuse
    re-arming writeability through every ndarray base. Spy on file reads to
    confirm metadata is read twice and only complete touched payloads are
    read, including successful repeated `verify_range` calls. Assert
    `retained_index_bytes` equals the pinned raw index size and enforce its
    1 MiB cap with a deliberately tiny block setting; no large fixture is
    necessary. Forbid `np.memmap`, `np.load` and pickle loads in these tests.
    An input proxy whose `__array__` raises must be rejected without calling it.
    Remove/bypass the digest check once and record that the mutation test fails;
    restore the implementation before verification.
19. [ ] Run the focused file and Ruff after freezing production. Record exact
    counts, source hashes, allocation/traffic observations and the mutation
    demonstration in the receipt. Commands:

    ```sh
    OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 uv run --no-sync pytest tests/test_distributional_row_store.py -q
    uv run ruff check src/superglm/distributional/row_store.py tests/test_distributional_row_store.py
    uv run ruff format --check src/superglm/distributional/row_store.py tests/test_distributional_row_store.py
    git diff --check
    ```

    Independent review checks steps 13–18, exact byte limits and the future
    cache-hit verification contract. Root handles commit/integration after
    review. Do not run numerical suites or benchmarks concurrently with root's
