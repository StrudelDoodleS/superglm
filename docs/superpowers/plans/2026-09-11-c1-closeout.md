# C1 Closeout Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development. One
> implementer and one reviewer maximum; execute the numbered packet, then review.

**Goal:** Complete the fixed C1 checklist without reopening completed work.
**Architecture:** Preserve the coupled solver and compiled model. Replace
full-row ownership with bounded preparation/replay, keeping existing eager
behavior and authenticated immutable chunk reuse.
**Tech Stack:** Python 3.12+, NumPy, SciPy, Numba and existing frame/model APIs.
**Spec:** [C1 closeout](../specs/2026-09-11-c1-closeout.md).

## Global constraints

- At most two subagents; implementation at high effort, independent review.
- Repository edits use apply_patch. Preserve unrelated QR work and versions.
- Preserve arithmetic order, weight semantics, model identity and certificates.
- New solver behavior needs a failing regression before the production change.
- Time full fits separately from instrumentation; use existing fixtures.
- No optional review ideas or additional acceptance targets enter this plan.

## Packet 1: Gaussian root preparation (acceptance item 3, partial)

**Owned production files:**
`src/superglm/distributional/family.py`, `families/gaussian.py`, `model.py`,
`fit_state.py`, `solver/solver.py`, `solver/_likelihood_cache.py` (all under
the same distributional directory).

**Tests:** Existing Gaussian weight, likelihood-cache and integration suites;
a focused new `tests/test_distributional_gaussian_preparation.py` if needed.

1. [ ] Demonstrate the root carrier's full-row ownership on the unfixed code.
   Capture the plan created by an actual public discrete Gaussian fit and its
   `parameter_independent_carrier.nbytes`; do not inspect only child scratch.
2. [ ] Add optional chunk-prepared binding with
   `bind_chunked_likelihood(y, weights, observation) -> FamilyLikelihoodPlan`.
   Declare derived prepared fields explicitly in the private reuse contract;
   absence alone never authorizes skipping source certification.
3. [ ] Implement an exact-Gaussian root without constructing its eager carrier.
   Retain the canonical plan type with an explicit absent root carrier. Stream
   the existing digest encoding in blocks of at most 8,192 rows. Prior carrier
   is `0.5 * log(w)`; frequency carrier is zero. Eager and derived plan IDs must
   match exactly, including partial tails and extreme valid weights.
4. [ ] Select this binding before public chunked fitting in `_fit_candidate`.
   Only the exact audited Gaussian type uses it. Custom subclasses and Gamma
   retain their existing binding; an inherited method must not override them.
5. [ ] Preserve owned eager children through `GaussianLikelihoodPlan.take`.
   Keep the current index rules, 64 MiB cache accounting, eviction and tail
   behavior. Children must not retain parent-buffer views or the parent plan.
6. [ ] At the existing null-fit boundary, create one eager null-only plan and
   release it after publication. Its logical ID must match. This is an explicit
   temporary compatibility boundary; acceptance item 4 remains unchecked.
7. [ ] Certify the derived variant and transform contract at the existing
   chunk-source boundary. Keep fresh checks of response, weights, offsets,
   links and designs. Stored carriers retain byte checks. Do not change the
   artifact schema or trust writable backing through a read-only view.
8. [ ] Verify prior/frequency likelihood and derivatives against independent
   Gaussian formulas; separately compare eager/derived IDs and children.
   Include offsets, zero-weight removal, nonmultiple chunks and extreme weights.
   Use dimension/epsilon/norm-derived tolerances for arithmetic comparisons.
9. [ ] Verify root allocation bounds and weak lifetimes, then mutations of
   weights/backing, metadata, variant and children. Cover null fitting,
   serialization, compact/full history and custom/Gamma fallback.
10. [ ] Freeze source and review the six-file ownership/certification change.
    Run focused affected suites and Ruff. Record any defects against steps 1–9
    and fix them before acceptance; no general numerical audit.
11. [ ] Use the existing million-row Gaussian fixture and smaller weighted
    Gaussian/Gamma controls. Compare complete outputs, convergence, histories,
    covariance, wall/CPU, peak RSS, retained root/cache bytes and dispatch.
    Profile separately to count carrier transforms and row passes. Expected
    retained payload reduction is `8*N` bytes; report the eager null cost.
12. [ ] Record the packet's commit and evidence. Check off only these substeps;
    acceptance items 2–7 remain governed by the full specification.

by gates 6 and 7. Their owner map is explicit in the execution ledger. Before
each implementation packet, freeze its exact interfaces, file ownership and
regressions against those requirements; do not add requirements or repeat the
