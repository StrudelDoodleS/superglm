# C1 closeout for the 0.32 release target

On 2026-09-11 the user separated 100-million-row/out-of-core support from this
closeout. The previous storage/compiler/solver expansion is deferred. This
specification supersedes its seven-item acceptance checklist.

The release target is a substantially complete C1 core, with demonstrated
limits and named follow-ups. A percentage is not a measured engineering result.

   the 10-million-row fit takes
   152.498 s with 11.055 GB peak process RSS and converges at rank 102. Both
   use discrete execution. These are fixture-specific observations.
4. [ ] Finish the scoped PR review and CI, address demonstrated findings and
   restore the ordinary Opus review workflow after the requested temporary
   Fable 5.1/max review.
5. [ ] Align the roadmap, plan and PR description with this scope. Keep the

## Separate follow-ups

- **100-million-row/out-of-core fitting:** a separate roadmap item. It requires
  its own architecture and feasibility scope; no such fit is required or
  claimed here. Further storage/compiler/solver work is paused.
- **12.5-second million-row target:** unmet and retained as a latency follow-up.
  The historical 15-second milestone remains evidence for its pinned source
  and conditions, not a guarantee for every subsequent machine run.
- General thread-policy and broader family/width scaling claims remain deferred.

The current fitter retains full-row inputs and some live/output state.
`discrete=True` does not imply constant whole-fit RAM. The 10-million-row result
does not certify arbitrary models, families, datasets or 100-million-row fits.

The deferred work is preserved locally on branch `deferred/c1-out-of-core`,
snapshot `92f99dda`, in `.worktrees/c1-out-of-core-deferred-20260911`. It includes
the reviewed row store and unfinished prepared compiler. It is outside this PR's
final implementation and has no completed fitting API.

At most two subagents. No optional numerical audit or new architecture enters
this closeout. Preserve unrelated QR edits. Reuse the existing verified source,
regressions and profiles; run new checks for actual changes or unresolved
